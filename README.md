# Security+ SY0-701 Acronym Simulator

Standalone offline-capable PWA for practicing the acronym vocabulary listed in the CompTIA Security+ SY0-701 exam objectives.

## Design
- Reuses the general architecture of the existing Security+ simulator but is a separate project.
- Dropdown-only questions.
- Approximately 50/50 mix of acronym -> full name and full name -> acronym.
- Handles acronyms with multiple meanings by adding context to keep each question unambiguous.
- 25, 50, 100, full-list, domain-focused, and weak-area tests.
- Detailed answer review after submission.
- Persistent local statistics for domains, topic areas, and individual acronyms.
- Weak-area practice mode.
- Offline PWA support for Android/tablet use.

## Scoring
This is a study score, not CompTIA's live exam scoring model.

## Domain grouping
The official objectives publish an acronym list, but do not map every acronym to exactly one domain. The app assigns each item a primary study domain and topic area for useful progress tracking.

## Source note
The acronym coverage is based on the CompTIA Security+ SY0-701 exam objectives acronym list. Explanations, question construction, categorization, and study tips in this simulator are original study material.
